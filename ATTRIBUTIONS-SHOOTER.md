# Shooter assets and references

- Kenney Blaster Kit 2.1: downloaded archive supplied by the owner. CC0, license retained in assets/blasters/License.txt. https://kenney.nl/assets/blaster-kit
- Kenney Building Kit: downloaded from Kenney's official itch.io page after the kenney.nl download returned HTTP403. CC0, license retained in assets/building_kit/License.txt. https://kenney.nl/assets/building-kit and https://kenney-assets.itch.io/building-kit
- Pixelify Sans: Google Fonts, SIL Open Font License; assets/ui/OFL.txt. https://github.com/google/fonts/tree/main/ofl/pixelifysans
- HUD hearts, weapon icons, arena collision geometry, tracer effects and weapon sounds are generated by project code. No Minecraft textures, sounds, logos, or game files are included.
- Existing robot characters and template assets retain their original attribution files under assets/.

Design references: Counter-Strike deathmatch's fast engagements and respawns; Fortnite Reload's readable gear and regrouping. This project uses an original map, original rules configuration and the separately licensed assets above.
